# DevSpace: Платформа для обмена кодом
Приветствуем в **DevSpace**! *Это легковесное веб-приложение*, созданное для того, чтобы разработчики могли мгновенно делиться сниппетами кода, оставлять заметки к проектам и организовывать свои мысли в удобном минималистичном интерфейсе. 

## Почему DevSpace?
***В мире перегруженных таск-трекеров мы сделали ставку на простоту.*** Никаких сложных регистраций и бесконечных настроек — только вы, ваш код и чистый фокус на продуктивности. Приложение оптимизировано для работы как на десктопах, так и на мобильных устройствах.

## Стек технологий️
* **Frontend:** HTML5, CSS3 (Tailwind CSS), JavaScript
* **Backend:** Node.js / Express
* **База данных:** MongoDB
